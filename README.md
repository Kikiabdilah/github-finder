# GitHub Finder
Aplikasi sederhana untuk mencari dan melihat profil pengguna GitHub.

# Deskripsi
GitHub Finder adalah aplikasi web berbasis JavaScript yang memungkinkan pengguna mencari profil GitHub, melihat detail profil, dan melihat daftar repositori publik milik pengguna. UI dirancang responsif dengan CSS dan markup HTML.

# Fitur
- Cari pengguna GitHub berdasarkan username
- Tampilkan detail profil (avatar, bio, followers, following, lokasi, link)
- Daftar repositori publik pengguna dengan link langsung
- Tampilan responsif untuk perangkat mobile dan desktop

# Instalasi
- Clone repository git clone https://github.com/Kikiabdilah/github-finder.git
- Masuk ke folder proyek cd github-finder
- Install dependensi npm install (atau yarn install)
- Jalankan aplikasi di mode pengembangan npm start (atau yarn start)
- Buka di browser: http://localhost:3000 (atau port yang tertera)

# Penggunaan
- Ketik username GitHub di kolom pencarian, tekan Enter atau klik tombol Search.
- Klik pada nama pengguna atau repository untuk membuka halaman GitHub asli.
